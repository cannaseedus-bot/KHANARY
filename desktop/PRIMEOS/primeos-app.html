PRIMEOS Documentation

App Platform

PRIMEOS hosts PowerShell micro-apps via a three-file trio: app.ps1 + app.program.json + app.ops.kuhul.

App Quartet Format

Visual apps (games, animations, comics, graphics) add a fourth file for shader addons:

apps/{id}/
  app.ps1             ← launch entry point
  app.program.json    ← metadata
  app.ops.kuhul       ← runtime ops (launch, health, build)
  app.shader.klsl     ← visual shader addon (optional, for visual apps)
// app.program.json
{
  "id": "com.khanary.my-app",
  "name": "My App",
  "version": "1.0.0",
  "category": "games",
  "entry": "app.ps1",
  "runtime": {
    "requires": ["kuhul_engine"],
    "min_vram_mb": 0
  },
  "permissions": ["inference", "filesystem:models"]
}
// app.shader.klsl — KLSL visual addon
@kind: "primeos.app.shader.v1"
@app:  "my-app"
@target: [webgl2, canvas2d, css]

skin {
  id:     "default"
  bg:     "linear-gradient(135deg, #0a0a2a, #010a1a)"
  accent: "#00e5ff"
  glyph:  "#0d9b7a"
}

pixel { id: "bloom"   mode: additive  radius: 4  intensity: 0.7 }
pixel { id: "scanline" mode: multiply step: 2   intensity: 0.06 }

animation {
  id: "idle-pulse"   target: ".glyph-col"
  property: opacity  from: 0.7  to: 1.0
  duration: 2s       easing: ease-in-out  repeat: infinite-alternate
}

Store tiles with shaders show a ✦ shader badge. The skin.bg replaces slides in the tile if present.

// app.ops.kuhul
ops inference {
  endpoint: kuhul_engine:17474
  models: [gemma-1b, from_zero]
}
ops tool_dispatch {
  endpoint: boss:8764
}

Model Aliases

All models are referenced by alias: gemma-1b, from_zero, lfm2, gpt2-xl, mgguf-gpt2, dolphin, phi3-mini and more. Aliases map to models/*/atomic.manifest.json.

Training

Use the Trainer Dashboard app for WebGL2, Native D3D11, PyTorch, and XSHARD training lanes. PyTorch: tools/pi_kuhul_train.py. Native: trainer/build/Release/gpt2_trainer.exe.
